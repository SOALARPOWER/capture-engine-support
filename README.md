# DMM/FANZA GAMES Capture Engine - Support

DMM/FANZA GAMES Capture Engine の
不具合報告・ゲーム互換性報告・サポート用リポジトリです。

## バグ報告

不具合が発生した場合は Issues から報告してください。

報告時には、可能な範囲で以下を記載してください。

- ゲームタイトル
- ゲームURL
- Capture Engineのバージョン
- 発生した問題
- 再現手順

Capture Engine本体のソースコードは公開していません。

## 注意

本ツールは非公式ツールです。
DMM GAMES / FANZA GAMES および各ゲーム運営元とは関係ありません。
