# DMM/FANZA GAMES Capture Engine - Support

このリポジトリは **DMM/FANZA GAMES Capture Engine** の  
サポート・不具合報告・ゲーム互換性報告専用リポジトリです。

Capture Engine本体のソースコードは公開していません。

## 不具合報告・ゲーム互換性報告

不具合や未対応ゲームを見つけた場合は、以下からご報告ください。

- [バグ報告](https://github.com/SOALARPOWER/capture-engine-support/issues/new?template=bug_report.yml)
- [ゲーム互換性・未対応ゲーム報告](https://github.com/SOALARPOWER/capture-engine-support/issues/new?template=game_compatibility.yml)

ゲーム固有の問題の場合は、可能な範囲で以下の情報も記載してください。

- ゲームタイトル
- ゲームURL
- Capture Engineのバージョン
- 発生した問題
- 再現手順
- スクリーンショット
- Capture Engineの診断情報

## 報告時の注意

Issueには、以下のような機密情報を投稿しないでください。

- Cookie
- token / access token
- ログイン情報
- 認証情報
- POSTデータ
- 署名付きURL
- セッション情報
- その他、第三者に公開すべきでない情報

Capture Engineから自動的に診断情報を付加する場合も、
これらの情報を送信しない設計としています。

## 本ツールについて

DMM/FANZA GAMES Capture Engineは、
DMM GAMES / FANZA GAMES上のゲームをより快適に表示・操作するための非公式Firefox拡張です。

主な機能には以下が含まれます。

- ゲームごとの表示領域解析
- 専用Captureウィンドウ
- ウィンドウ / 全画面表示
- 左右半画面配置
- ゲーム領域の拡大縮小
- 壁紙表示
- スクリーンショット
- Burst PNG連写
- 録画用Clean Mode
- ゲームごとのProfile / Adapter

ゲーム側の更新や配信方式の変更などにより、
一時的に正常動作しなくなる場合があります。

その場合は、ゲーム互換性報告からお知らせいただけると助かります。
